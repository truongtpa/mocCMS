# mocCMS

Starter Laravel 11, Vue 3 và bộ khung quản trị tự dựng trên Bootstrap 5.

## Cài đặt

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
```

## Phát triển

```bash
composer run dev
```

## Build

```bash
npm run build
```
